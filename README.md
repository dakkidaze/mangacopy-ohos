# MangaCopyOHOS

拷贝漫画（mangacopy.com）的 **HarmonyOS NEXT** 第三方客户端 —— **纯 ArkTS 重写版**（`arkts` 分支）。

功能对齐 Flutter 基准实现（`main` 分支，基于 [jimytao/copymanga](https://github.com/jimytao/copymanga)）。
技术栈：**ArkTS（ArkUI 声明式）+ ArkWeb**；ArkTS 应用位于 `harmony/`。

> ⚠️ 本项目与「拷贝漫画」官方**没有任何关系**，仅供个人学习研究。详见文末**免责声明**。

## 功能现状

### 浏览（两种方式，退出设置后切换生效）
- **网页版**：套壳网页版 H5（保留登录页等站内功能）
- **原生界面（默认）**：发现（热门/最新）、搜索、筛选、漫画详情；
  详情页章节为**一行一章**，每章右侧带**下载**按钮
- 多线路自动切换；可在设置中自定义 API 域名

### 阅读
- **自带原生阅读器**：横向 / 纵向 / 条漫三种模式，双击缩放 / 双指捏合缩放、
  音量键翻页、断点续读、原地切章 + 下一章预取、页码跳转、**左右开本（阅读方向）**
- **章节边界二次确认**：到末页再翻 / 再滑一次才切章，避免误触
- **点击章节 → 直接进原生阅读器再加载**（不再出现网页阅读器）
- **章节图片两种取数方式**（设置 → 章节图源，切换立即生效）：
  - **网页收图（默认）**
  - **API 取图**：直连官方 `/api/v3` 取章节图片
- 离线章节直接读本地图；失败自动重载；条漫宽高比自适应

### 吐槽（评论）
- 章末吐槽 + 漫画总评（官方 `/api/v3`，**免登录可读**）
- 两种入口：
  - 阅读器工具栏 **「吐槽」按钮** → 弹窗（章末吐槽 + 总评）
  - 章节**最后一页之后的「吐槽」虚拟页**（横/纵/条漫皆有，仅章末吐槽，可在设置关闭）
- **离线章节也能读吐槽**（下载时写入章节元数据）；无网络时自动跳过

### 下载 / 离线
- 单章下载（阅读器 / 详情页），**批量下载**（详情页多选章节）
- **下载管理页**：进行中任务实时进度、**等待中排队**、失败重试 / 移除、一键取消
- **我的下载**：已完成内容两级浏览（漫画 → 章节），章节页支持**批量删除**
- 离线阅读；下载文件协议稳定（元数据 / `.done` 标记 / 章节清单）

### 账号
- **原生登录**；登录状态会保留，下次打开仍是登录态
- 收藏书架、浏览历史（原生界面「更多」内；未登录会提示先登录）

### 外观与体验
- 深色模式（含 **AMOLED 纯黑**）、隐藏状态栏（时间 / 网络胶囊）
- 页面转场、按压反馈、缩放与列表回弹等动效

### 暂不实现
- **轻小说**：暂不支持
- **发布吐槽**：仅支持查看，不支持发布
- **弹幕**：客户端与基准均不涉及（站点侧功能）

## HarmonyOS 构建

- ArkTS 应用位于 `harmony/`，使用 **DevEco Studio** 或 **hvigor** 构建
  （`hvigorw assembleHap`），产物为**未签名 HAP**，请自备证书签名后安装。
- 运行环境：HarmonyOS NEXT（ArkTS / ArkWeb）。
